# Nwosu Precious Chinenyenwa: Portfolio

Live site: https://nwosu-precious.github.io

## Publish (first time)
1. Create a public repository named exactly **Nwosu-Precious.github.io**.
2. Upload everything in this folder (index.html, assets/, .nojekyll, README.md) to the repository root.
3. Go to Settings > Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. The site goes live at https://nwosu-precious.github.io within a few minutes.

## Update the CV (no coding)
1. Rename your new CV to exactly `Nwosu_Precious_CV.pdf`.
2. Open the repository, go to `assets/docs/`, click **Add file > Upload files**.
3. Drop the PDF in and click **Commit changes**. It replaces the old one, and every Download CV button updates automatically.

## Edit text
All text is in `index.html`, grouped by section (look for comments such as `<!-- ===== RESEARCH ===== -->`). Click the file, then the pencil icon to edit in the browser.

## Add a photo
Upload the image to `assets/img/`, then copy an existing `<button data-lb=...><img ...></button>` line in the Industry events section and change the file name and caption.
